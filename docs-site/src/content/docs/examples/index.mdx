import { CardGrid, LinkCard } from '@astrojs/starlight/components';

Each guide tests a small public app from the [tester-army](https://github.com/tester-army) example repositories (MIT licensed). The apps are not part of this repository. Clone one, run it, and write the tests in your own test project. Every snippet is C# for E2E for .NET, and its test ids and texts come from the app's README and tests.

These guides are .NET-only pages. Upstream lists the five apps in its examples registry and renders each app's README as the page, so there was no guide text to port. The snippets compile against the packages, and the guides say which steps need a model, a simulator, or a store.

| Guide | App | Platform | Needs a model |
| --- | --- | --- | --- |
| [Three languages](/examples/i18n/) | A Nuxt contact form in English, German, and Spanish | Web | One of three tests |
| [File uploads](/examples/file-upload/) | A Next.js image upload to Vercel Blob | Web | No |
| [Location](/examples/location/) | An Expo app that shows the city you are in | iOS, Android | No |
| [Face ID and fingerprint](/examples/biometrics/) | An Expo lock screen with a PIN fallback | iOS, Android | One test |
| [Deep links](/examples/deep-links/) | An Expo app that opens orders from links | iOS, Android | No |
